Our process

We build self-improving world models.

A program is a model you can run. A large language model holds a rich picture of how the world works, and writing code turns that picture into a world model it can run, test, and improve.
Given a task, it writes a world model of the domain, generates safe experiments to resolve only what it still needs to know, and tests its predictions against reality. What it learns goes back continually into the model. We call this interactive learning.
The same loop runs in code, in the lab, and in robots. Every solution paves the way for the next. Over time the system discovers new science and invents new things, including its own models and everything beneath them.
